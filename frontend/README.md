# React Query Events Frontend

The React and TypeScript client for React Query Events, built with Vite, TanStack Query, and React Router.

## Requirements

- Node.js 20.19 or newer
- npm

## Development

```bash
npm install
npm run dev
```

The development server runs at http://localhost:5173. Start the repository's backend separately on port 3000.

## Quality Commands

```bash
npm test
npm run typecheck
npm run build
```

Use `npm run test:watch` while developing and `npm run preview` to inspect the production bundle locally.
